1️⃣  INSTALAR DOCKER (si no lo tienes)
   └─ https://www.docker.com/products/docker-desktop
   └─ Reinicia tu PC después


2️⃣  ABRIR TERMINAL EN LA CARPETA DEL PROYECTO
   └─ Windows: Click derecho → Abrir en terminal
   └─ Mac/Linux: Terminal → cd /ruta/al/proyecto


3️⃣  LEVANTAR BASE DE DATOS
   ┌─────────────────────────────────────────┐
   │ cd backend                              │
   │ docker-compose up -d                    │
   │                                         │
   │ ⏳ Espera 15 segundos...                │
   └─────────────────────────────────────────┘


4️⃣  EJECUTAR BACKEND (Terminal 1)
   ┌─────────────────────────────────────────┐
   │ cd backend                              │
   │ npm install                             │
   │ npm run start:dev                       │
   │                                         │
   │ ✅ Espera hasta ver:                    │
   │ "Listening on port 3000"                │
   └─────────────────────────────────────────┘


5️⃣  EJECUTAR FRONTEND (Terminal 2)
   ┌─────────────────────────────────────────┐
   │ cd frontend                             │
   │ npm install                             │
   │ npm run dev                             │
   │                                         │
   │ ✅ Espera hasta ver:                    │
   │ "Local:  http://localhost:5173"         │
   └─────────────────────────────────────────┘


🌐 ACCEDER A LA APP
   ┌─────────────────────────────────────────┐

   │ Backend API: http://localhost:3000      │
